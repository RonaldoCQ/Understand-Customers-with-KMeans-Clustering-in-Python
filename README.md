# Customer Segmentation with K-Means Clustering

A hands-on data science project focused on customer segmentation using K-Means clustering algorithm in Python, made following a tutorial from TrentDoesMath.

## 📌 About the Project

Customer segmentation is a data analysis technique used to group customers according to shared characteristics and behavioral patterns.

In this project, I explore how **K-Means clustering**, an unsupervised machine learning algorithm, can be applied to customer data to identify distinct groups without relying on predefined labels.

The goal is to transform raw customer data into meaningful segments that can support exploratory analysis, help identify patterns, and inform data-driven business decisions.

## 🎯 Objectives

- Explore and understand the customer dataset.
- Perform data cleaning and preprocessing.
- Apply K-Means clustering to identify customer segments.
- Analyze the characteristics of the resulting clusters.
- Visualize the results and interpret the identified patterns.
- Understand how unsupervised machine learning can support business analysis.

## 🛠️ Technologies Used

- **Python**: Data analysis and model implementation.
- **Pandas**: Data manipulation and preprocessing.
- **NumPy**: Numerical computations.
- **Matplotlib**: Data visualization.
- **Seaborn**: Statistical visualization.
- **Scikit-learn**: K-Means clustering and machine learning tools.
- **Jupyter Notebook**: Interactive development and experimentation.

## 🧠 Methodology

The project follows a typical unsupervised learning workflow:

1. **Data exploration:** Examine the dataset, understand its variables, and identify relevant customer attributes.
2. **Data preprocessing:** Handle missing values, inspect data quality, and prepare the features for analysis.
3. **Feature selection:** Choose the variables that will be used to measure similarities between customers.
4. **Clustering:** Apply the K-Means algorithm to partition customers into groups based on their feature values.
5. **Cluster evaluation:** Assess the clustering results and, if appropriate, investigate the optimal number of clusters.
6. **Visualization and interpretation:** Analyze the resulting groups and identify meaningful differences between customer segments.
